# P_SAPEA Study Guide — 2026 refresh

This folder is a complete static replacement site for the OrdoAnimi P_SAPEA GitHub Pages guide.

## Files
- `index.html` — complete site content
- `styles.css` — responsive visual design
- `app.js` — mobile navigation, section highlighting and local progress tracker

## Deploy to GitHub Pages
1. Open the GitHub repository for the existing site.
2. Back up the current files.
3. Replace the existing site files with these three files.
4. Commit the changes.
5. GitHub Pages will publish the site from the configured branch/folder.

No build step, framework or package installation is required.

## Important maintenance rule
SAP's certification program is changing. Before each major revision, verify the current P_SAPEA certification page and SAP Learning certification guidance. Do not hard-code an exam duration, package price, attempt bundle, or assessment mechanic unless it is currently confirmed by SAP.
